Evapotranspiración de referencia (Blaney-Criddle y Hargreaves-Samani) y consumo del cultivo ETc

Datos de entrada

Para calcular el consumo del cultivo (opcional)

Ingrese latitud, mes y temperaturas para ver el cálculo.
Fórmulas y supuestos
Blaney-Criddle: ETo = p · (0,46 · Tmed + 8,13) [mm/día] Hargreaves-Samani: ETo = 0,0023 · Ra · (Tmed + 17,8) · √(Tmáx − Tmín) ETc = ETo · Kc

p es el porcentaje diario de horas de luz respecto al total anual, calculado con la latitud y el día central del mes. Ra es la radiación extraterrestre en mm/día (FAO-56). Febrero se toma con 28 días. Blaney-Criddle usa solo temperatura media; Hargreaves-Samani agrega el rango térmico diario como indicador de radiación. Son estimaciones: para riego de precisión conviene contrastarlas con una estación meteorológica local.

Dimensiones y volumen de un reservorio troncopiramidal según demanda, autonomía y margen de seguridad

Datos del reservorio

Forma de la base (opcional)

Los datos anteriores no definen la forma por sí solos: con el mismo volumen hay infinitas combinaciones de largo y ancho. Esta relación fija una.

Ingrese los datos del reservorio para ver el cálculo y el esquema 3D.
Fórmulas del reservorio
V diseño = demanda diaria · autonomía · (1 + margen / 100) V = (h / 3) · (A base + A boca + √(A base · A boca)) Largo boca = largo base + 2 · talud · h Ancho boca = ancho base + 2 · talud · h

Se resuelve el ancho de la base que entrega exactamente el volumen de diseño, con la profundidad, el talud y la relación largo : ancho indicados. El volumen corresponde al reservorio lleno hasta el borde, sin bordo libre. Es un dimensionamiento preliminar: no incluye impermeabilización, vertedero, bordo libre, pérdidas por infiltración ni evaporación, ni estudios de suelo y estabilidad de taludes.

Lámina de riego, lámina neta y frecuencia de riego

Datos del suelo y del cultivo

Las láminas se calculan sobre el área neta (superficie realmente regada). CC y PMP se ingresan como humedad gravimétrica (%), tal como las reporta el laboratorio.

Ingrese los datos para calcular las láminas y la frecuencia de riego.
Fórmulas utilizadas
Lr (L/m²) = (CC − PMP) / 100 · Profundidad de raíz (mm) · Da Lr (m³) = Lr (L/m²) · Área neta / 1000 Ln (L/m²) = Lr (L/m²) · Agotamiento / 100 Ln (m³) = Ln (L/m²) · Área neta / 1000 Frecuencia (días) = Ln (m³) / ETr (m³/día)

La frecuencia siempre se redondea hacia el número entero mayor (4,22 → 5; 4,82 → 5). Es un cálculo preliminar: no incluye eficiencia de aplicación, lluvia, aporte capilar ni variación del Kc durante el ciclo.

Caudales por sector y horas de riego en sistemas por goteo

Datos del sistema de riego

Datos de referencia (opcionales)

Estos dos datos no entran en el cálculo del tiempo de riego. Si ingresa la ETr, la página también muestra la frecuencia de riego (Ln / ETr, redondeada hacia arriba).

Ingrese los datos del sistema para calcular el tiempo de riego.
Fórmulas utilizadas
Plantas por sector = Número de plantas / Sectores Total de goteros = Número de plantas · Goteros por planta Caudal total (m³/h) = Caudal del gotero (L/h) · Total de goteros / 1000 Caudal por sector (m³/h) = Caudal total / Sectores Ln por sector (m³) = Ln / Sectores Tiempo de riego (h) = Ln por sector / Caudal por sector

Se asume que los sectores tienen igual número de plantas y que se riegan uno a la vez, con el caudal total dividido entre ellos. El tiempo es el de cada sector; el tiempo total del evento es ese valor por el número de sectores. Es un cálculo preliminar: no incluye eficiencia de aplicación, pérdidas de presión ni variación de caudal de los goteros.
